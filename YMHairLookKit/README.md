# YM Hair Look Kit

髪周りのルック調整を非破壊で行える Unity + NDMF 向けツールです。

## 概要

- 髪マテリアルの結合、眉ステンシル、FakeShadow、輪郭線補正を非破壊で適用します。
- `YM MToon to lilToon` と同じアバターにある場合は、変換後の lilToon マテリアルに対して処理します。
- `YM MToon to lilToon` がない MToon モデルでは、MToon のまま髪マテリアル結合だけを実行できます。
- 元のマテリアルを直接変換せず、NDMF のビルド処理と Preview 上で非破壊に結果を確認できます。

## 機能

### マテリアル最適化

#### 髪マテリアル結合

- 全マテリアルから結合対象を選択できます。MToon、lilToon、その他のシェーダーのマテリアルも一覧に表示されます。
- `HAIR_`、なければ `hair` を含み `back` を含まない名前を優先して自動選択します。大文字小文字は区別しません。
- 結合後の代表マテリアルを指定できます。影色、アウトライン色、描画モードなどは代表マテリアルを基準にした結合結果になります。
- 前髪と後ろ髪が異なる GameObject / Renderer に分かれていても、選択された髪全体で 1 つの結合マテリアルと共通アトラスを生成します。
- Renderer と Mesh 自体は統合しません。各 Renderer の髪サブメッシュへ同じ結合マテリアルを割り当てるため、後段のメッシュ最適化ツールでまとめやすい構成になります。
- 結合後のアトラス上限サイズを 256 x 256 から 8192 x 8192 まで選択できます。
- 指定した上限より小さいサイズで収まる場合は、小さいアトラスサイズで処理します。
- 結合対象が論理的に 1 マテリアルだけの場合は、テクスチャを再生成せず元のテクスチャを維持します。
- メインテクスチャだけでなく、影色、Emission、Normal、Shadow Mask、Outline Mask なども可能な範囲でアトラス化します。
- 異なるシェーダー/描画モード/Cull設定のマテリアルが混在していても、警告を出して代表マテリアル基準で処理します。
- MToon のまま使う場合でも髪マテリアル結合は実行できます。

### lilToon固有機能

#### 眉ステンシル

- 髪の手前に眉を表示するためのステンシル設定を適用します。
- 対象は lilToon、または同じアバター上の `YM MToon to lilToon` で lilToon 化される MToon マテリアルです。
- MToon のまま処理するモデルでは使用できません。
- 髪対象は「結合した髪マテリアル」または個別マテリアルから選択できます。

#### FakeShadow

- 前髪の疑似落ち影を生成し、顔マテリアルと髪マテリアルに必要なステンシル設定を適用します。
- FakeShadow の描画済み領域はステンシル bit 6 に記録し、交差した髪ポリゴンによる同一ピクセルへの重複描画を防ぎます。
- 合成モードは「乗算」と「比較(暗)」から選択できます。初期値は「乗算」です。
- 対象は lilToon、または同じアバター上の `YM MToon to lilToon` で lilToon 化される MToon マテリアルです。
- MToon のまま処理するモデルでは使用できません。
- 髪対象は「結合した髪マテリアル」または個別マテリアルから選択できます。

#### 輪郭線補正

- ハードエッジ向けの補正です。同一座標の法線を平均し、頂点カラー RGB に焼き込んで輪郭線を整えます。
- 対象は lilToon、または同じアバター上の `YM MToon to lilToon` で lilToon 化される MToon マテリアルです。
- 髪対象は「結合した髪マテリアル」または個別マテリアルから選択できます。
- 個別マテリアルを選んだ場合は、平均法線の焼き込みのみを行います。
- 「毛先の太さ」「毛先の範囲」は、このツールで髪マテリアル結合を行う VRoid 向けのオプションです。「結合した髪マテリアル」を選んでいる場合だけ適用されます。
- 毛先調整は、結合前の VRoid 髪 UV を基準に毛先を判定します。結合後のアトラス UV では判定しません。

## 処理順

ビルド時と Hair Look Kit の Preview では、おおむね次の順で処理します。

1. 同じアバターに `YM MToon to lilToon` があり、連携 Preview が必要な場合は MToon 変換を先に実行します。
2. 髪マテリアル結合を実行します。
3. 結合結果を含む現在のマテリアル参照を解決します。
4. 眉ステンシル、FakeShadow、輪郭線補正を適用します。

`YM MToon to lilToon` 側の Preview は MToon から lilToon への単体変換のみを表示します。髪ルック調整まで含めた見た目は `YM Hair Look Kit` 側の Preview で確認します。

## Preview

`YM Hair Look Kit` の Preview は髪ルック処理の結果を表示します。  
同じアバターに `YM MToon to lilToon` がある場合は、Preview Avatar 上で先に MToon 変換を実行してから Hair Look Kit を適用します。

`YM MToon to lilToon` 側の Preview は単体変換だけを表示します。

MToon モデルで `YM MToon to lilToon` がない場合、Preview では MToon 変換を経由せず、髪マテリアル結合だけを適用した見た目を確認できます。

## ビルドターゲット分岐

輪郭線補正は PC 向けの処理です。ビルド時に対象が mobile と判定される場合、輪郭線補正はスキップされます。

mobile 判定は以下の順で行います。

1. アバター直下に VRCQuestTools の `PlatformTargetSettings` がある場合、その `buildTarget` を優先します。
   - `Android` の場合は mobile として扱います。
   - `PC` の場合は PC として扱います。
2. VRCQuestTools の設定がない場合は `EditorUserBuildSettings.activeBuildTarget` を参照します。
   - `Android` / `iOS` の場合は mobile として扱います。
   - それ以外は PC 向けとして扱います。

mobile 判定でスキップされるのは輪郭線補正のみです。髪マテリアル結合、眉ステンシル、FakeShadow の判定とは独立しています。

## 注意

- MToon のまま髪結合する場合、眉ステンシル、FakeShadow、輪郭線補正はスキップされます。
- 「結合した髪マテリアル」を選んでいるのに髪マテリアル結合がオフの場合、そのカテゴリはエラーとなります。
- 個別マテリアルを選んでいて、そのマテリアルが髪マテリアル結合の対象になっている場合、そのカテゴリはエラーとなります。
- lilToon 固有機能で lilToon として処理できないマテリアルを選んだ場合、そのカテゴリはエラーとなります。
- 髪マテリアル結合は代表マテリアル基準でまとめるため、同じシェーダー/描画モード/Cull設定でも見た目が多少変わることがあります。
