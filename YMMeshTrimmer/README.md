# YM Mesh Trimmer

透明テクスチャのアルファを元に、見えない部分のポリゴンをビルド時に削除する NDMF ツールです。  
VRoid 顔パーツを比較的高めの精度でトリミングできるため、Quest 対応が楽になります。
PC 向けにポリゴン数を減らしたい場面でも使えます。

## 使い方

1. アバター配下に `Yoridori Modifiers/YM Mesh Trimmer` を追加します。
2. `有効ビルドターゲット` で適用したいビルド先を選びます。
3. 必要に応じて `アルファしきい値`、`マスク拡張`、`マスククリーンアップ`、`微小ポリゴン除去` を調整します。
4. `Preview` で削除結果を確認します。
5. `トリミング対象` を開くと、検出されたマテリアルごとの設定を確認できます。

## Preview

`Preview` を押すと、元アバターを隠して Preview 用アバターを表示します。  
別の GameObject を選択しても Preview は維持されます。

Android または iOS が有効な場合、Preview 用マテリアルは Toon Standard 相当のシェーダに切り替わります。  
これにより、Android / iOS 向けの見え方に近い状態で確認できます。

処理中は `Processing...`、失敗時は `Failed`、Preview 中はポリゴン数が表示されます。

Preview 表示が残ったり、モデルが見えなくなった場合は、`Advanced` の `Reset Preview` を押してください。

## 設定

### 有効ビルドターゲット

`Windows`、`Android`、`iOS` を複数選択できます。  
同じアバター内で同じビルドターゲット向けに複数の Trimmer が有効な場合は警告が出ます。

ビルド時は、現在のビルドターゲットに一致する Trimmer のうち、アバター階層内で最初に見つかった1つだけが実行されます。  
それ以降に見つかった同ビルドターゲット向けの Trimmer は無視されます。  
Inspector の警告には、そのコンポーネントがビルド時に使われるか、無視されるかが表示されます。

### アルファしきい値

メッシュを残すか削除するかを判定するアルファ値です。  

### マスク拡張

残す領域をピクセル単位で外側に広げます。  
服の端や顔パーツの境界が削れすぎる場合に大きくします。

### マスククリーンアップ

小さな穴や孤立した領域を軽く整理します。
内部では、まず小さな孤立領域をごみ取りし、その後にマスク拡張、隙間埋め、小さい穴埋めの順で処理します。

### 微小ポリゴン除去

トリミング後に極端に小さく残るポリゴンを削除します。

## トリミング対象

`トリミング対象` foldout には、対象マテリアルごとの設定が表示されます。  
初期状態では折りたたまれています。

- `事前細分化`
  - トリミング精度を上げるため、処理前に該当メッシュを細分化します。
  - 設定 JSON にルールがある場合は、その初期値が反映されます。
- `塗り足し`
  - `None`: テクスチャを変更しません。
  - `FillColor`: 透明部分の RGB を指定色で合成します。
  - `Solidify`: 透明部分の RGB を近くの不透明または半透明ピクセルから塗り広げます。

`Solidify` は十分なアルファを持つピクセルを元にRGBを塗り広げます。圧縮によって透明境界に生じた低アルファの暗色も近傍色で補修し、アルファ値自体は変更しません。

## カスタム設定 JSON

プロジェクト内の `Assets/YM-Mesh-Trimmer-Setting.json` に設定 JSON を置くと、同梱の `YMMeshTrimmer/Settings.json` の代わりに使われます。
ユーザー JSON は同梱設定への追加ではなく、完全な置き換えです。

塗り足し色だけ指定する最小例です。

```json
{
  "fillColors": [
    {
      "target": ["eyeline"],
      "source": ["faceskin"],
      "uv": [0.3242, 0.4902]
    }
  ]
}
```

事前細分化だけ指定する最小例です。

```json
{
  "preSubdivide": [
    {
      "target": ["eyelash"],
      "level": 1
    }
  ]
}
```

複数の設定をまとめて指定する例です。

```json
{
  "fillColors": [
    {
      "target": ["eyeline", "アイライン"],
      "source": ["faceskin", "face_00_skin", "顔"],
      "uv": [0.3242, 0.4902]
    }
  ],
  "preSubdivide": [
    {
      "target": ["eyelash", "まつげ", "睫毛"],
      "level": 1
    }
  ]
}
```

- `trimAlgorithm` (optional)
  - 省略時は `edgeCrossing` です。
  - `edgeCrossing`: 現在の標準方式です。透明領域との交差を使って切断形状を作ります。
  - `legacyInsidePoint`: 旧方式です。既存の内側判定ルートを使います。新方式で欠けやとげが出るアバター向けの互換用です。
- `fillColors` (optional)
  - `target` に一致したマテリアルの塗り足しを `FillColor` にし、`source` に一致したマテリアルのメインテクスチャから `uv` 座標の色を取得します。
- `preSubdivide` (optional)
  - `target` に一致したマテリアルへ事前細分化の初期値を反映します。
  - `level` は `0` から `2` の範囲です。
  - `0` は無効、`1` は各三角形を1段階細分化、`2` はさらに細かく細分化します。
  - 値が大きいほどトリミング精度は上がりやすくなりますが、処理後の頂点数と処理時間も増えます。

## プリセットでの追加

Hierarchy でアバターを右クリックし、`Yoridori Modifiers/Create YM Components Object for VRoid` または `Yoridori Modifiers/Add Component with VRoid Defaults/YM Mesh Trimmer` から追加すると、Mesh Trimmer は2つ追加されます。

- Android/iOS 用
  - Android と iOS が有効
  - 標準設定
- Windows 用
  - Windows が有効
  - `マスク拡張`: `12px`
  - `アルファしきい値`: `0.01`

## 注意

手動ほどの精度はなく、どうしても多少のとげや欠けは発生します。
特殊な UV、極端に細かいメッシュ、半透明表現が多いマテリアルでは、Preview で確認しながら調整してください。
