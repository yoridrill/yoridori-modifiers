# YM Mesh Trimmer

透明テクスチャのアルファを元に、見えない部分のポリゴンをビルド時に削除する NDMF ツールです。  
VRoid 顔パーツを比較的高めの精度でトリミングできるため、Quest 対応が楽になります。
PC 向けにポリゴン数を減らしたい場面でも使えます。

## 使い方

1. アバター配下に `Yoridori Modifiers/YM Mesh Trimmer` を追加します。
2. `有効ビルドターゲット` で適用したいビルド先を選びます。
3. 必要に応じて `アルファしきい値`、`マスク拡張`、`マスククリーンアップ`、`微小ポリゴン除去` を調整します。
4. `Preview` で削除結果を確認します。
5. `トリミング対象` を開くと、検出されたマテリアルごとの設定を確認できます。

## Preview

`Preview` を押すと、元アバターを隠して Preview 用アバターを表示します。  
別の GameObject を選択しても Preview は維持されます。

Android または iOS が有効な場合、Preview 用マテリアルは Toon Standard 相当のシェーダに切り替わります。  
これにより、Android / iOS 向けの見え方に近い状態で確認できます。

処理中は `Processing...`、失敗時は `Failed`、Preview 中はポリゴン数が表示されます。

Preview 表示が残ったり、モデルが見えなくなった場合は、`Advanced` の `Reset Preview` を押してください。

## 設定

### 有効ビルドターゲット

`Windows`、`Android`、`iOS` を複数選択できます。  
同じアバター内で同じビルドターゲット向けに複数の Trimmer が有効な場合は警告が出ます。

### アルファしきい値

メッシュを残すか削除するかを判定するアルファ値です。  

### マスク拡張

残す領域をピクセル単位で外側に広げます。  
服の端や顔パーツの境界が削れすぎる場合に大きくします。

### マスククリーンアップ

小さな穴や孤立した領域を軽く整理します。

### 微小ポリゴン除去

トリミング後に極端に小さく残るポリゴンを削除します。

## トリミング対象

`トリミング対象` foldout には、対象マテリアルごとの設定が表示されます。  
初期状態では折りたたまれています。

- `事前細分化`
  - トリミング精度を上げるため、処理前に該当メッシュを細分化します。
  - 設定 JSON にルールがある場合は、その初期値が反映されます。
- `塗り足し`
  - `None`: テクスチャを変更しません。
  - `FillColor`: 透明部分の RGB を指定色で合成します。
  - `Solidify`: 透明部分の RGB を近くの不透明または半透明ピクセルから塗り広げます。

`Solidify` は `alpha > 0` のピクセルを元に塗り広げます。  

## プリセットでの追加

Hierarchy でアバターを右クリックし、`Yoridori Modifiers/Add VRoid Preset` から追加すると、Mesh Trimmer は2つ追加されます。

- Android/iOS 用
  - Android と iOS が有効
  - 標準設定
- Windows 用
  - Windows が有効
  - `マスク拡張`: `12px`
  - `アルファしきい値`: `0.01`

## 注意

手動ほどの精度はなく、どうしても多少のとげや欠けは発生します。
特殊な UV、極端に細かいメッシュ、半透明表現が多いマテリアルでは、Preview で確認しながら調整してください。
